# Переводы по номеру телефона

## 1. Общие сведения

Документ описывает сервис переводов по номеру телефона.

## 2. Лимиты

Суточный лимит перевода составляет 100 000 руб. для базового тарифа.

## 3. Функциональные требования

1. Система должна быстро проверять номер телефона получателя.
2. Система проверяет статус клиента, наличие блокировок и т.д.
3. По возможности система должна показывать имя получателя.
4. Комиссия за перевод TBD.
5. Перевод на сумму до 50 000 руб. выполняется без комиссии.
6. Система отправляет запрос в платёжный шлюз и списывает средства.

## 4. Интеграция

Сервис вызывает платёжный шлюз по REST.
